# windows-server-active-directory-lab

## Overview
Hands-on cybersecurity lab focused on configuring and managing Windows Server and Active Directory lab covering user management, groups, permissions, organizational units, and access control.

## Lab Environment

-Windows Server
-Active Directory Domain Services (AD DS)
-Windows client environement
-Virtualized lab environment

## Objectives

- Configure a Windows Server Active Directory environment
- Create and manage domain users and security groups
- Organize users and resources using Organizational Units (OUs)
- Configure and verify user permissions
- Apply least-privilege access principles
- Troubleshoot domain and connectivity issues

  ### Active Directory Configuration

- Configured Active Directory Domain Services
- Created and managed domain users
- Created and configured security groups
- Organized users and resources within Organizational Units
- Assigned and verified user permissions

### Access Control

- Configured access based on user and group membership
- Verified that users had appropriate access to assigned resources
- Applied least-privilege concepts when assigning permissions

### Troubleshooting

- Investigated Windows domain connectivity and configuration issues
- Verified user accounts, group membership, permissions, and system configuration
- Documented findings and adjustments made during the lab

## Security Concepts

- Active Directory administration
- Identity and access management
- Least privilege
- Role-based access control
- User and group management
- Permission management

## What I learned

This lab provided hands-on experience with Windows Server and Active Directory in a controlled environment. I gained a better understanding of how organizations manage users, groups, permissions and access control within a windows domain. This lab also reinforced the importance of least privilege and verifying access after making configuration changes.
